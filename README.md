# Synergia — plateforme de tontines et d'épargne collective

Nom de travail provisoire, à confirmer. Application web construite avec
Next.js (App Router), TypeScript et Tailwind CSS, déployée en continu sur
Vercel à mesure de son avancement.

## Démarrer en local

```bash
npm install
npm run dev
```

Le site est alors accessible sur http://localhost:3000.

## Feuille de route (modules)

1. Fondations, design system, page vitrine — en cours
2. Authentification, profil et vérification d'identité (KYC)
3. Groupes et gestion des membres
4. Cycle de tontine et tirage au sort
5. Épargne collective (projets et événements)
6. Paiements Mobile Money et flux financiers (modèle escrow)
7. Tableaux de bord, notifications et audit trail

Chaque module est développé, déployé sur un aperçu Vercel, puis validé
avant de passer au suivant.

## Identité visuelle

- Couleurs : encre profonde (`--color-ink`), ivoire (`--color-ivory`),
  or discret (`--color-gold`), vert émeraude (`--color-emerald`).
- Typographies : Fraunces (titres) et Inter (texte courant).
- Aucune icône : la hiérarchie visuelle repose sur la typographie, les
  filets et les espacements.
